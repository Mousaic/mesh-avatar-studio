# 经验记录

做播报视频流水线时踩过的坑和用过的办法。总的原则：**先量化再改，先查环境再查代码。**

## 一、Windows 环境

| 现象 | 真正原因 | 解决 |
|---|---|---|
| `npm run create` 报 "Codex CLI was not found" | Node 的 `spawn('codex')` 不能运行 npm 装的 `codex.cmd` | 把 Codex 自带的 `codex.exe` 所在目录放到 PATH 最前面，再运行 |
| Live 页一直显示"未检测到面部" | 摄像头的电子隐私开关关着，画面全黑；电脑上还有一个红外摄像头 | 打开开关，设备选 Integrated Camera，不要选带 IR 的 |
| 输出重定向后 `tts.py` 报编码错误 | 控制台编码打不出中文 | `tts.py` 已改成遇到无法编码的字符就替换 |
| 系统里没有 ffmpeg | — | 用 `uv run --with imageio-ffmpeg` 自带的 ffmpeg，不装系统软件 |
| 编辑器网页突然打不开 | 开发服务器被停掉了 | 在仓库根目录重新运行 `npm run dev` |

排查摄像头时，把链路拆开逐段测：

```
摄像头画面 ──► 追踪模型 ──► GPU / CPU ──► Live 页的 Worker
   ↑ 先看画面亮度：0 就是全黑，后面不用再查
```

## 二、头像

- Codex 做一个头像约 40 分钟。做完先读项目里的 `HANDOVER.md`，它会列出没通过的检查。
- 头像本身的瑕疵会带进视频，例如半闭眼差分画得不好，眨眼时会出现几帧重影。
- 构图要按图片实际的不透明区域计算。原图底部常有透明边，直接铺满会让半身像悬空。`make.mjs` 按 `base.png` 的不透明范围自动缩放和定位。
- 引擎自带的情绪配套动作不一定合适：`angry` 配的摇头动作（`no`）会把眼睛闭成笑眼，所以 `[生气]` 只换表情、不播动作。
- 眉毛被刘海挡住的头像，生气、难过的效果会偏弱。

## 三、语音和对口型

```
Edge（免费）  只有按词的时间，词里的字平均分
豆包 2.0      enable_subtitle 后，事件 364（TTSSubtitle）给出逐字时间，从整段音频开头计时
语气指令      context_texts 作用于一个会话 → 按表情标记切段，每段一个会话，音频按顺序拼接
```

- 豆包句尾最后一个字的结束时间偏早，但声音还在。处理：一个字结束后，只要声音还在，就保持它的嘴型（最多 0.6 秒）。
  不要按"字缝小于多少秒就填上"来补，那样会把真正的停顿也填满，停顿时嘴合不上。
- 嘴巴动得太快，是因为编辑器的"标准"风格每个字都开合一次。播报用 `news` 风格（0.15, 0.5, 0.35），再加音量包络平滑。
  不要直接用 `calm`：短停顿时嘴合不上。
- 张口幅度和嘴型要一起考虑：嘴型由拼音决定，张口幅度由引擎按音量计算。
- 语气指令有效果，但强弱不一：实测"平静"变慢、变低，"害羞"音高明显升高，"难过"变化不明显。可以改 `tts.py` 里的 `TONES` 文字加强。

## 四、方法

1. **用数据判断。** 每次改动前后都量这几项：

   | 指标 | 意义 | 目标 |
   |---|---|---|
   | 有声帧被某个字覆盖的比例 | 时间戳准不准 | 越高越好 |
   | 安静帧被当成说话的比例 | 停顿处会不会乱动嘴 | 越低越好 |
   | 每秒完整开合次数 | 嘴动得快不快 | 播报约 0.5～1.5 |
   | 每帧张口变化 | 抖不抖 | 越低越好 |
   | 停顿时闭嘴的比例 | 逗号处能不能合上 | 100% |

   有两次第一版修复反而更糟（补字缝、`calm` 风格），都是靠这些数字发现的。每帧的张口数据记录在 `projects/<头像>/work/broadcast/<稿子>/mouth.json`。
2. **做对比视频。** 同一段语音，左右并排放改前和改后。
3. **调参不花额度。** `--reuse-speech` 复用已经合成的语音，只重算时间轴和画面。
4. **抽帧检查。** 用 ffmpeg 抽出关键时刻的脸部画面拼成一张图，一次看完所有表情或嘴型。
5. **声音要人听。** 音高、语速只能粗略反映语气，最终效果要人耳确认。

## 五、密钥和版权

- `broadcast/.env` 有两层忽略：本地的 `.git/info/exclude`，以及提交进仓库的 `broadcast/.gitignore`。
- 提交前扫描暂存内容，确认没有类似密钥的长字符串，也没有 `.env` 或 PDF。
- 火山引擎文档（`1.pdf`）声明不得转发，不提交。
- 头像图片和生成的视频放在 `projects/`，按项目规则不提交。
