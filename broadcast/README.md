# 播报短视频批量生成

把播报稿（`.txt`）批量做成竖屏 MP4：语音合成朗读，头像按音量和拼音对口型，带标题栏和字幕。

## 语音引擎

| 引擎 | 选项 | 时间精度 | 配置 |
|---|---|---|---|
| 火山引擎豆包 2.0（推荐） | `--engine doubao` | 每个字的起止时间 | `broadcast/.env` |
| 微软 Edge（免费） | `--engine edge`（默认） | 每个词的起止时间，词内平均分配 | 无 |

豆包的配置：把 `broadcast/.env.example` 复制成 `broadcast/.env`，填 `TTS_API_KEY`。
可选的 `TTS_SPEAKER` 是音色 ID（控制台 → 音色库里的 2.0 音色），也可以用 `--voice` 临时指定。
`.env` 已被 git 忽略，不会被提交。

```
稿子.txt ──► tts.py ──► speech.wav + timeline.json（每帧音量、嘴型、字幕时间）
                              │
                              ▼
            make.mjs：无头浏览器逐帧渲染头像 + 标题 + 字幕 ──► ffmpeg ──► MP4
```

## 用法

在仓库根目录运行：

```sh
node broadcast/make.mjs projects/<头像项目> broadcast/scripts --engine doubao
```

第二个参数可以是一个 `.txt`，也可以是文件夹（处理里面所有 `.txt`，每篇出一条视频）。

视频输出到 `projects/<头像项目>/videos/<稿子文件名>.mp4`。
语音和时间轴在 `projects/<头像项目>/work/broadcast/`。

## 稿子格式

```
# 标题（可选，显示在顶部红色标题栏）
第一句话。
第二句话，可以有逗号。
```

字幕按句号、逗号自动切分，每条最多约 16 个字。

## 表情标记

在稿子里写 `[开心]` 或 `【开心】`，从后面第一个字开始换表情（提前约 0.15 秒），一直保持到下一个标记。
标记不会被读出来，也不会出现在字幕里。

```
[开心]大家好！今天给大家带来一个好消息。
[惊讶]你知道吗？只用一张插画，就能做出会说话的主播！
[害羞]谢谢大家的支持，[眨眼]我们下次见！
```

| 标记 | 效果 |
|---|---|
| `[开心]` `[高兴]` | 笑眼、脸红，点一下头 |
| `[惊讶]` `[吃惊]` | 睁大眼睛，头往后一仰 |
| `[难过]` `[伤心]` | 下垂的眼睛和嘴角，叹一口气 |
| `[生气]` `[愤怒]` | 半睁眼、皱眉（不带动作） |
| `[平静]` `[放松]` | 柔和的眼神，身体轻轻摇摆 |
| `[害羞]` | 脸红、视线微移 |
| `[无语]` `[眯眼]` | 半睁眼 |
| `[眨眼]` | 单眼眨一下（约 0.7 秒） |
| `[正常]` `[默认]` | 恢复默认表情 |

写错的标记会在运行时提示，并被忽略。

### 语气联动（豆包）

用 `--engine doubao` 时，标记还会改变**说话语气**：每段文字带上一条豆包 2.0 的语音指令（`context_texts`）。

| 标记 | 语音指令 |
|---|---|
| `[开心]` | 用开心、愉快的语气说 |
| `[惊讶]` | 用惊讶的语气说 |
| `[难过]` | 用难过、低落的语气说 |
| `[生气]` | 用生气、不满的语气说 |
| `[平静]` | 用平静、放松的语气说 |
| `[害羞]` | 用害羞、轻柔的语气说 |
| `[无语]` | 用无奈的语气说 |
| `[眨眼]` | 用俏皮的语气说 |
| `[正常]` | 不加指令 |

每种语气是一个单独的合成会话，音频按顺序拼接，时间戳会自动接上。
只想换表情、不换语气时，加 `--no-tone`。指令文字在 [tts.py](tts.py) 的 `TONES` 里，可以自己改。

## 选项

| 选项 | 默认值 | 说明 |
|---|---|---|
| `--engine` | `edge` | 语音引擎：`edge` 或 `doubao` |
| `--voice` | Edge：`zh-CN-XiaoxiaoNeural`；豆包：`.env` 里的 `TTS_SPEAKER` | Edge 男声可用 `zh-CN-YunxiNeural`、`zh-CN-YunyangNeural`（新闻风格）；豆包填音色 ID |
| `--rate` | `+0%` | 语速，例如 `+10%`、`-5%`（豆包范围 -50% ~ +100%） |
| `--no-tone` | 关 | 豆包：表情标记只改表情，不改语气 |
| `--lip` | `news` | 嘴巴动作风格，见下表；也可以写三个 0～1 的数：`断音灵敏度,张口幅度,闭合速度`，如 `0.15,0.5,0.35` |
| `--reuse-speech` | 关 | 复用上次合成的语音，只重算时间轴和画面（调参时用，不消耗豆包额度） |

### 嘴巴动作风格（`--lip`）

| 风格 | 数值 | 效果 |
|---|---|---|
| `news`（默认） | 0.15, 0.5, 0.35 | 适合播报：只在明显的音节低谷处闭合，停顿时闭嘴 |
| `calm` | 0, 0.5, 0 | 最慢；短停顿时嘴可能合不上 |
| `default` | 0.5, 0.5, 0.5 | 编辑器的"标准"：每个字都张合一次，偏快 |
| `lively` | 1, 0.5, 1 | 最快 |
| `subtle` / `big` | 0.5, 0 或 1, 0.5 | 张口小 / 张口大 |

调参示例：

```sh
node broadcast/make.mjs projects/<头像项目> broadcast/scripts/xx.txt --engine doubao --reuse-speech --lip 0.1,0.6,0.3
```
| `--bg` | `#0b1f3a` | 背景色，或背景图片路径 |
| `--size` | `1080x1920` | 画面尺寸。横屏可用 `1920x1080` |
| `--fps` | `30` | 帧率 |

## 需要的工具

Node.js、uv、Playwright Chromium（`npm run doctor` 能检查）。
Python 依赖（edge-tts、pypinyin、numpy、imageio-ffmpeg）由 uv 临时安装，ffmpeg 来自 imageio-ffmpeg，不用另外装。

## 隐私

只有稿子文字会发送到语音服务（微软 Edge 或火山引擎）。头像图片和渲染全部在本机完成。

## 已知限制

- 嘴型按拼音韵母映射到 あ/い/う/え/お。豆包按字对齐；Edge 在同一个词里平均分配时间。
- 豆包给句尾最后一个字的结束时间偏早，脚本会在声音持续时保持该字的嘴型（最多 0.6 秒）。
- 数字和英文按"あ"处理。
- 表情要在稿子里手动标记，不会根据内容自动判断。
- 眉毛被刘海挡住的头像，生气、难过的效果会比较弱。
